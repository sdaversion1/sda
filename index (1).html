Achète d’abord ton domaine chez un vendeur (Namecheap, Hostinger, Cloudflare…), puis colle-le ici.

TypeNomValeur

Ouvre les réglages DNS de ton domaine chez ton vendeur, ajoute un enregistrement CNAME avec ces valeurs, puis reviens ici. Cela peut prendre de 5 minutes à quelques heures.

📡 Code de suivi Pagéo

Tes pages créées dans Pagéo sont suivies automatiquement. Si tu as aussi des pages ailleurs (Systeme.io, WordPress…), colle ce code juste avant </body> : Pagéo comptera les visites, les vidéos lancées, les clics WhatsApp et récupérera les formulaires.

<script src="https://pageo.app/suivi.js" data-compte="awa" defer></script>

Ce que le code récupère

  • Chaque visite, avec le pays, l’appareil et la source (Facebook, TikTok…).
  • Chaque vidéo lancée et chaque j’aime.
  • Chaque clic vers WhatsApp.
  • Chaque formulaire envoyé : nom, numéro, pays, adresse, produit.
